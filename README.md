# Astrea.3D — Projeto pronto

Este pacote contém um site original e responsivo para a marca Astrea.3D, acompanhado de um design system em JSON, uma direção de arte para o asset principal e os prompts da atividade.

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta `astrea3d_projeto`.
3. Dê dois cliques em `index.html` para visualizar no navegador.
4. Se algum recurso não carregar corretamente, abra a pasta no VS Code e inicie um servidor local (por exemplo, Live Server).

## Arquivos
- `index.html`: estrutura do site.
- `styles.css`: identidade visual e responsividade.
- `script.js`: menu mobile e ano automático.
- `design-system.json`: tokens e regras visuais.
- `asset-direcao-arte.json`: especificação do visual principal.
- `prompts-prontos.md`: prompts A a F alinhados ao roteiro da aula.

## Personalização necessária antes de publicar
- Confirme se o Instagram `@Astrea.3D` é o canal correto.
- Inclua fotos reais dos produtos quando estiverem disponíveis.
- Atualize descrições, prazos, materiais, preços e condições de entrega conforme a operação real.
- O site não contém formulário de pagamento nem sistema de pedidos; o contato é direcionado ao Instagram.

## Sobre o benchmark e a skill
O site deste pacote é uma criação original baseada em uma direção visual definida para o projeto. Não foi apresentado como cópia de um site externo. A extração automatizada com `/extract-ds` depende da ferramenta em que a skill for instalada e executada; por isso, o pacote já inclui um design system documentado e editável em JSON.
